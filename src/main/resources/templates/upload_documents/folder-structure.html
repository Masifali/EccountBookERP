Create Folder Structure
The folders and files live on the Windows share (configuration "RootPathForShareFolderStructure"), which the browser cannot reach. Here the folder tree and the file records in the database are maintained: Add Child New Folder adds the folder record only (the directory is not created on the share), Delete Folder and Delete (file) remove the database records only (the directory / file stays on the share), and Upload File, opening a file, thumbnails, file size and file date are not available.
